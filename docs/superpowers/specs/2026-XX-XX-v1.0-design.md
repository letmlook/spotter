# v1.0.0 平台生产级设计

## 目标

让 spotter 从 0.x 玩具级发布升级到 1.0 生产级：跨平台原生封装、Linux 包仓库、SSH-only 操作场景下的 CLI。

## 范围（in-scope）

### 1. macOS 集成
- **Codesign + Notarize**：GitHub Actions runner 触发 `xcrun notarytool`，凭据来自 repo secrets
- **DMG 打包**：`create-dmg/create-dmg@v1`，文件名 `Spotter-<version>-darwin-<arch>.dmg`
- **原生菜单栏**：Wails `AppMenu`、`EditMenu` 注入 `Cmd+Q/W/C/V/+`
- **Dock 图标自定义**：build/darwin/iconfile.icns 已生成，logo 与 metadata 自动应用

### 2. Linux 包
- **deb 仓库**：`scripts/packages/deb/` + `aptly` 构建，仓库源挂载到 `apt.spotter.dev`
- **OpenRC / runit 脚本**：`scripts/init/openrc/spotterd` + `scripts/init/runit/spotterd/run`，作为 systemd 替代
- **Homebrew tap**：`spotter/homebrew-tap`（formula scaffold 在本仓）

### 3. CLI / TUI 子命令
- `cmd/spotter-cli/`：list / scan / info / version 子命令
- `cmd/spotter-cli/tui.go`（v1.1）：bubbletea + lipgloss，写只读 TUI
- 目的：FAQ "Wails 是 GUI-only" 的根治

### 4. 跨平台 CI 矩阵
- `release.yml` 增加 `client-darwin-{amd64,arm64}` + `client-windows-amd64`
- 需要新 runners：`macos-13/14`、`windows-2022`
- `scripts/build-all.sh` 已支持 host-only 构建；CI 加矩阵入口

### 5. release 签名
- `sigstore/cosign` 对所有产物 sign-blob
- 生成 SLSA provenance attestation
- `dist/SHA256SUMS` + `dist/SHA256SUMS.cosign` + provenance.intoto.jsonl 全部 publish

## 不在范围

- iOS / Android 客户端（v1.x 后续）
- 自动下载 + 自动应用更新（v1.1，需要 codesign 的 signing 链）

## 验收

- [ ] macOS CI 在 self-hosted runner 上能完成 codesign + notarize
- [ ] deb 包可 apt-get install
- [ ] homebrew tap `brew install spotter/tap/spotter` 成功
- [ ] `spotter-cli list` 在 headless 环境正常工作
- [ ] GitHub Release 同时附 SHA256SUMS、cosign bundle、SLSA provenance

## 风险与回滚

- Apple Developer 账号未续费 → codesign 失败 → CI 跳过 macOS 段
- APT signing key 泄露 → apt-key rotation
- Homebrew formula 被打回 → 修依赖即可重提
